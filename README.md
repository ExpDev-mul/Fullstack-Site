# ⚛️ Fullstack Site

This is the **React + Vite** frontend for a simple fullstack web app showcasing common features like user authentication and API integration.

## ✨ Features

- 🧾 Account creation & login
- 🔐 Forgot password flow
- 🌐 API interaction via REST
- ⚡ Fast dev setup with Vite
- 🎨 Clean UI with responsive layout

## 🔧 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/ExpDev-mul/Fullstack-Site.git
   cd Fullstack-Site/frontend
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the dev server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:5173](http://localhost:5173) in your browser.

## 📦 Build

To create a production build:
```bash
npm run build
```
